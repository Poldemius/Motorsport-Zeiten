# 🏎️ Motorsport Hub – F1, MotoGP & Junior Series

Ein übersichtliches Dashboard für Motorsport-Fans, das alle Renntermine und Session-Zeiten der beliebtesten Rennserien auf einen Blick zusammenfasst.

![Motorsport Hub Banner](https://img.shields.io/badge/Status-Aktiv-brightgreen)

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

---

## 🌟 Features

* **🏎️ Alle Klassen vereint:** Zeiten für **Formel 1, F2, F3, F1 Academy, MotoGP, Moto2 und Moto3**.
* **🌍 Automatische Zeitzone:** Alle Session-Zeiten werden automatisch in die lokale Uhrzeit des Besuchers umgerechnet.
* **⏳ Live Countdown:** Zeigt sekundengenau an, wann die nächste Session startet.
* **🎯 Filter-Funktion:** Filtere den Kalender nach deinen bevorzugten Rennserien.
* **📅 Kalender-Export (.ics):** Lade dir das komplette Rennwochenende mit einem Klick direkt in dein Smartphone (Apple, Google, Outlook) herunter.
* **📱 Responsive Design:** Optimiert für Smartphone, Tablet und Desktop.

---

## 🛠️ Technologien

* **HTML5 & CSS3:** Modernes, dunkles Layout (Dark Mode Dashboard).
* **JavaScript (Vanilla):** Automatische Zeitzonenberechnung und Timer-Logik – ohne schwere Frameworks.
